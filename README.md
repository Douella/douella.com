# דואלה | אתר תדמית

אתר סטטי בעברית (RTL) של אלה גנץ, דולה והכנה ללידה (דואלה), עם עמוד בית אחד: הירו, אודות, ארבעה שירותים (ליווי מלא ושלושה קורסי הכנה), תהליך עבודה, המלצות ויצירת קשר בוואטסאפ, טלפון, אינסטגרם ופייסבוק.

## תצוגה מקומית

פתחו את `index.html` בדפדפן, או הריצו שרת מקומי:

```bash
python3 -m http.server 8000
```

ואז פתחו `http://localhost:8000`.

## פרטי קשר ועדכונים

פרטי הקשר עודכנו ומרוכזים בראש `site.js` באובייקט `CONTACT`:

```js
const CONTACT = {
  phone: "+972559100445",
  phoneDisplay: "0559100445",
  whatsapp: "972559100445",
  instagram: "https://www.instagram.com/ella_gantz_doula",
  instagramHandle: "@ella_gantz_doula",
  facebook: "https://www.facebook.com/ella.gantz/",
  facebookLabel: "אלה גנץ · דולה והכנה ללידה"
};
```

פרטי הקשר עודכנו גם ב-JSON-LD שבתחילת `index.html` (`telephone` ו-`sameAs`) וביעדים הסטטיים של הקישורים, למקרה שה-JavaScript לא נטען. מספר התצוגה הוא `0559100445` ומספר הוואטסאפ הבינלאומי הוא `+972559100445`.

### תוכן ועדכונים

- **המלצות:** חמש ההמלצות בעמוד הן אמיתיות, והצילומים המקוריים שלהן נמצאים ב-`assets/testimonials/` ונפתחים ב-lightbox. אם מוסיפים או מחליפים המלצה, עדכנו גם את הכרטיס ב-`index.html` ואת `data-lightbox-src` בהתאם.
- **שם העסק והמותג:** האתר משתמש בשם "דואלה" ובשם "אלה גנץ". אם המיתוג שונה, יש לעדכן אותו בכל מקום (`index.html`, `README.md`, `site.js`, `assets/favicon.svg`).
- **תמונות:** תמונת ההירו נמצאת ב-`assets/photos/ella-hero.jpg`, תמונת הדיוקן ב-`assets/photos/ella-about.jpg`, ושתי תמונות הגלריה ב-`assets/photos/`. אם מחליפים תמונה, שמרו על יחס תמונה אנכי ועדכנו את ה-`alt` בהתאם.
- **פרטי מקצוע:** הכשרה, ניסיון, אזורי שירות וזמינות. הנוסח הנוכחי מכוון ולא ממציא נתונים; הוסיפו רק מה שנכון.
- **קישור לדף מדיניות פרטיות:** אם מוסיפים טופס, פיקסלים או אנליטיקס.

## עיצוב

- פלטה חמה: קרם, טרקוטה, מרווה וזהב.
- פונטים: Frank Ruhl Libre לכותרות, Heebo לגוף.
- RTL מלא, עם שימוש בתכונות לוגיות (`inset-inline`, `margin-inline`).
- נגישות: קישור דילוג, מבנה סמנטי, מיקוד ברור, ניגודיות צבעים, תפריט דיאלוג נגיש, תמיכה ב-`prefers-reduced-motion`.
- אין תלות בספריות צד שלישי מלבד Google Fonts.

## פריסה

האתר סטטי לחלוטין, ולכן מתאים ל-GitHub Pages, Netlify, Vercel או כל אחסון סטטי. אם משתמשים בדומיין `douella.com`, אפשר להוסיף קובץ `CNAME` בשורש עם הערך `douella.com` (בהתאם להגדרות האחסון).

## בדיקות לפני פרסום

- פתחו את האתר בנייד ובמחשב.
- בדקו שכל קישורי וואטסאפ, הטלפון, האינסטגרם והפייסבוק מובילים ליעד הנכון.
- בדקו שהתפריט נפתח ונסגר במקלדת (Tab, Enter, Escape).
- בדקו שכל ההמלצות והצילומים מאושרים על ידי הלקוחות.
- ודאו שכל טקסט שנשאר מתאר את השירות שלכם בצורה מדויקת.
